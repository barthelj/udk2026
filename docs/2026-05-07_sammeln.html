Website der Münchner Verkehrsgesellschaft MVG

Schritt 1: Was wünscht sich die Website-Betreiberin – was dürfen wir automatisiert auslesen? → robots.txt

Schritt 2: Wir schauen uns um: Was brauchen wir? → Developer-Tools öffnen (Rechtsklick oder Tastenkombination, je nach Browser + Betriebssystem) → Tipp: Interessant ist oft “Network → XHR”.

NoteWas ist XHR?

Webseiten bestehen technisch aus HTML-Code. Hier haken “echte Programmierer” gern ein und korrigieren: HTML ist aber nur eine Auszeichnungssprache, das hat nichts mit Code zu tun.

Stimmt: HTML heißt HyperTextMarkupLanguage und kann vor allem verschiedene Elemente auf einer Website darstellen: Eine Überschrift auf dem höchsten Level wird markiert mit <h1> am Anfang und </h1> am Ende, eher eine Unterüberschrift mit <h2> und </h2>, eine Unterunterüberschrift mit <h3> und </h3> und so weiter…

Links sind oft interessant, die sind gekennzeichnet mit <a href="https://example.com">Hier klicken</a>. Hier klicken steht dann in Link-Formatierung auf der Website. Der Teil in Anführungszeichen hinter href= ist die URL, wo man hingeleitet wird.

Wenn jetzt eine Website was “können” soll, sich also anpassen oder Daten laden, dann nutzt man dafür JavaScript. Das ist eine Programmiersprache, die beispielsweise “wenn, dann…”-Befehle ausführen kann: “Wenn drei Sekunden vorbei sind, dann zeigst du ein neues Bild an, lieber Browser.” Oder eben: “Wenn dieser Code geladen wird, dann hole bitte die Daten im Hintergrund von folgender Website.”

Und solche Daten werden dann im Hintergrund übertragen, ohne dass die Website neu geladen werden muss, mittels eines “XHR”, oder ausgeschrieben “XMLHttpRequest”. Der Server bekommt also eine Anfrage: Ey, gib mal Daten. Und zwar in verschiedenen Formaten, XML steht im Namen, kann aber auch JSON sein.
